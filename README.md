
# BLACKOUT

**Personal AI Assistant for Android**

BLACKOUT is an Android-based personal AI assistant inspired by advanced onboard computer systems and underground automotive culture.

## Vision
- Voice-controlled AI assistant
- Persistent personal memory
- Local and online AI capabilities
- Android device integration
- Internet research
- Custom automotive-inspired interface

## Modes
- STREET — Everyday assistance
- GHOST — Discreet operation
- REDLINE — Advanced research and reasoning
- GARAGE — Automotive assistance

## Development
Built for Android using Kotlin and Jetpack Compose.

**Status:** Early development.
